# Site Web – Flamme Trans d'Afrique

Architecture multipage complète développée en HTML5, CSS3 et JavaScript vanilla.

## Structure du projet
- `index.html` : Page d'accueil complète (Hero, Présentation, 6 activités, Solutions, Engagements, Couverture géographique interactive, Secteurs, CTA, Footer).
- `about.html` : Page institutionnelle (Présentation, Mission, Vision, Valeurs, Expertise & Méthodologie).
- `services.html` : Présentation détaillée des 6 activités principales (Transport national, Transport international, Transit, Groupage, Affrètement, Consignation).
- `solutions.html` : Modes de transport (Routier, Maritime, Aérien, Multimodal, Expéditions nationales et internationales).
- `destinations.html` : Couverture géographique interactive et zones à valider.
- `contact.html` : Formulaire de demande de devis complet avec validation et coordonnées officielles.
- `style.css` : Charte graphique *African Global Logistics* (`#C62828`, `#142B45`, `#F28C28`, `#F3F5F7`, `#FFFFFF`).
- `script.js` : Navigation responsive, menu déroulant, animations au défilement, carte interactive et validation du formulaire.
- `assets/logo/logo-flamme-trans.svg` : Logo vectoriel original.

## Avant mise en production
1. Compléter les mentions `[À compléter par l'entreprise]` (coordonnées, téléphone, WhatsApp, adresse, mentions légales, pays et villes officiellement desservis).
2. Connecter l'endpoint API d'envoi d'e-mails dans `script.js` (ligne 121).
